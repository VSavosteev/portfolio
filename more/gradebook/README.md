# Информационная система контроля успеваемости обучающихся

Практические работы по дисциплине «Проектирование информационных систем», бакалавриат МИРЭА, 2023.

Что сделано:
- техническое задание по ГОСТ 34;
- диаграмма вариантов использования UML с описанием прецедентов;
- функциональная модель в IDEF0 (Ramus);
- архитектура системы на MySQL, JavaScript и HTML.
