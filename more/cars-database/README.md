# База данных спортивных автомобилей

Девять практических работ по дисциплине «Проектирование и разработка баз и хранилищ данных», магистратура МИРЭА.

Что сделано:
- логическая модель и нормализация вплоть до 6НФ;
- перенос данных из исходной таблицы в нормализованные (`INSERT ... SELECT DISTINCT`);
- выборки, агрегаты, подзапросы, представления и CTE;
- функции и триггер на PL/pgSQL: счётчик автомобилей по модели обновляется при вставке;
- сравнение производительности запросов в PostgreSQL и MongoDB.

SQL из работ лежит в папке [`sql/`](sql/), по файлу на практическую работу.
