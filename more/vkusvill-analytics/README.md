# Аналитический комплекс КИС для управления продажами ВкусВилл

Курсовая работа, МИРЭА.

Тема: обработка данных в аналитических комплексах КИС для управления продажами.

Что сделано:
- определены цели управления процессом продаж;
- спроектирована архитектура аналитического комплекса: слой вычислений на KNIME, слой визуализации на Yandex DataLens;
- автоматизирована обработка данных: выбраны и применены алгоритмы машинного обучения в KNIME;
- собраны визуальные аналитические отчёты и дашборды в DataLens.
